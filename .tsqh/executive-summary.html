The product claim

Creative work stays flexible. Control stays deterministic.

Agents edit and report outcomes. Native commands preserve their exit semantics. A pure planner reads validated facts and follows only explicit configured edges—failing closed whenever evidence is missing, malformed, unauthorized, or exhausted.

What was built

A complete vertical slice

The repository moved from documentation-only to a working pnpm package with strict source, schema, CLI, fixtures, examples, tests, and operational evidence.

01

Strict configuration

Ajv schema validation plus semantic graph checks reject unknown properties, references, paths, missing edges, invalid visit limits, and unreachable terminal behavior before commands or filesystem mutation.

02

Deterministic controller

An immutable reducer and pure planner select canonical actions from the workflow, event trace, process outcomes, and visit counts—with no filesystem, process, clock, provider, or network dependency in the domain.

03

Fail-closed execution

Commands run as executable-plus-argument arrays with the shell disabled. Git fingerprints enforce role write scopes, policy files stay protected, output is bounded, and failures become exact blockers.

How it works

One action at a time

Every agent references a logical role, every role resolves a prompt and provider, and every gate resolves a native quality profile. Names and order remain configuration.

Bounded repair: a nonzero gate exit follows only its configured failure edge to the repair role, returns to the configured gate, and blocks when a visit budget would be exceeded.

Runtime sequence

From input to evidence

Preflight checks happen before side effects. Once a run starts, each transition is justified by a recorded native outcome and persisted for audit.

1

Validate first

Load strict JSON, validate the graph, resolve prompts beneath the configuration root, and read the exact task.

2

Prove workspace state

Require an explicit existing Git worktree root with a clean candidate before creating the run trace.

3

Plan and execute

Start one configured agent or gate, capture its native process result, then validate Git changes where applicable.

4

Reduce facts

Append a contiguous JSONL event and reduce the immutable trace into current state, visits, outcome, and blocker.

5

Follow one edge

The pure planner follows only the matching configured outcome edge and checks the target visit budget.

6

Finish exactly

Reach a configured terminal with exit 0, or finish nonzero with a structured blocker that explains why.

Quality coverage

MVP-complete, not quality-stack complete

The controller can execute any configured native profile. The follow-up contract is now explicit in TSQH-MVP-002; implementation still awaits dependency and Sonar target approval.

Enforced today

  • Strict source and test TypeScript checking
  • Reproducible build on Node.js 22 or newer
  • 36 deterministic Vitest tests across six files
  • Domain dependency-boundary verification
  • Real authenticated Codex smoke workflow
  • Native exit status, timeout, signal, and path enforcement

Specified next gates

  • Fresh V8 coverage: ≥90% globally and 100% for the domain
  • @azaru/tscrap: every production unit at CRAP ≤ 6
  • Stryker: nonempty inventory with every mutant killed
  • Knip: complete-project analysis with zero findings or hints
  • Sonar: current LCOV and a server-computed OK gate
  • Fail-fast order: quick → coverage → CRAP → Knip → mutation → Sonar

Important: the names quick and full describe configurable workflow stages. The current full remains version 0 evidence; it must not be presented as the new hardening gate until every stage runs for real. Missing tools, reports, credentials, or external gate state fail closed.

Operate it

Two commands

run executes a validated workflow in the foreground. status validates and reduces an existing trace without mutating it.

pnpm tsqh run \ --config examples/workflow.json \ --workspace /absolute/path/to/clean-git-worktree \ --task /absolute/path/to/task.md \ --json pnpm tsqh status --run /absolute/path/to/run-directory --json
Scope

Deliberately small

Version 0 proves the unattended sequential guardrail loop without importing advanced orchestration infrastructure before it is needed.

Included now

  • Strict JSON schema and semantic graph validation
  • Configurable roles, providers, prompts, profiles, and transitions
  • Sequential native gates and bounded repair
  • Clean-worktree and role-path enforcement
  • Bounded append-only JSONL trace and read-only status
  • Generic local command provider

Explicitly deferred

  • Concurrency, batches, daemon, and remote execution
  • Managed worktrees, merge authority, and branch leases
  • Crash-safe resume, locks, snapshots, and cache
  • Dashboards, servers, provider SDKs, and arbitrary plugins
  • Same-account hostile-process protection
  • Advanced evidence DAGs and semantic approvals
