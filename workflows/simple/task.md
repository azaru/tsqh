# Simple TDD workflow assignment

Use TDD to add `src/smoke-marker.ts` exporting the constant string `TSQH_SMOKE_OK`. The `tester`
must first add the complete behavioral test suite needed to validate the assignment, including all
relevant edge cases, under `test/`. The tests must exercise observable behavior only, never
implementation details. The `implementer` must then add the production export and make the full
suite pass. Do not change any other file.
